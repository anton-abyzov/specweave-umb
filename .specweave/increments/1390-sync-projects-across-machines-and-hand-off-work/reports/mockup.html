Machines sync files. Work is handed off.

Proposal for increment 1390. The words Main and Copy leave the interface. A project lives on several machines as equals, and three verbs cover everything you do between them. Mockup with specweave's machines and the M4's Git state of November 18. Nothing here is built.

filesSyncGit first: pull on both machines, fast-forward only, clone a repository that is missing. Work Git does not carry is offered as extras.
files, first timeAddPut the project on a machine that does not have it: download from GitHub, plus optional extras from the source machine.
workHand offThreads, unsaved work and the coordinator conversation continue on another machine. By hand, or by itself on sleep or at a limit.

What a hand off does, in order

1 CheckM5 reachable, signed in, room for the files. Anything that cannot go is named before you press.
2 SyncM5 pulls. A repository that cannot fast-forward holds only the threads that need it.
3 ThreadsEach thread's work travels as a hidden checkpoint. A thread across several repositories goes whole or stays.
4 CoordinatorConversation moves last. m4 stops starting work.
5 Keepm4 keeps every file and a read-only copy of each thread. "Bring work back" reverses it.

5. By itself, for one or two threads

Off unless you turn it on. A thread's ⋯ menu gets "Hand off automatically", which replaces "Keep ready to move".
