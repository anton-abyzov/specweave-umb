Agent navigation in the thread agent popover

Live work and anything waiting on you come first, results you haven't seen come next, and history is folded away. The order is set when the popover opens and stays put while you read; changes show up in place or in a pill you press.

Before and after: the 1041 design thread

Same data as the October 24 screenshot: 5 workflows, 55 subagents, 2 working.

While you read

Nothing moves under the pointer. A finished agent changes its dot and label in place. New agents and group changes wait in a pill. Anything that needs you gets its own pill that jumps straight to it.

  • Inside a group, rows sort only on timestamps that never change (start, finish, request time). Last activity is used to detect quiet runs and never to sort, so constant updates can't reshuffle the list.
  • A parent ranks by its most urgent descendant, so a workflow with one agent waiting on you sits in Needs you.
  • The sidebar and Threads pane keep their current stable order. This change only affects the agent popover.
