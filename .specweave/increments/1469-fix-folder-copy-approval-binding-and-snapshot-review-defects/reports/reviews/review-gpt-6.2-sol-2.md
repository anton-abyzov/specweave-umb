## [high] apps/server/src/fleet/folderTransfer/manifest.ts:570 The recorded root identity does not identify the tree actually inventoried

The inventory and probe set can describe the other tree. For example, if the inventory saw an ordinary config too large for the probe but the captured tree has a small secret-bearing config at that path, the entry is selected as ordinary and capture skips the content check (secretContent.ts:179, sourceSnapshot.ts:327). Capture accepts the stable file's actual size and digest (sourceSnapshot.ts:472), and the saved captured copy validates without a fresh source scan (sourceService.ts:1081). Bind the inventory and content reads to the same directory identity used by capture. Re-verified by reading.
